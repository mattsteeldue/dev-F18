    🖥️ **vForth for VS Code** — new, alongside build 20260820

    A small VS Code extension for writing vForth: `vforth-0.1.0.vsix` in the `tools/` folder of the repo, with a quick-start next to it.

    **Editing**
    • Syntax colouring from the real core dictionary — core, library and your own words look different
    • Warns when a library word is used before its `NEEDS`, and says which one to add
    • Hover = its `HELP` page + where it's defined; go to definition works on `NEEDS`/`INCLUDE` too

    **CSpect tools**
    • *Push file to SD image*: copies the file you're editing into the image **while CSpect is running**. No `REMOUNT`, nothing to close — type `NEEDS` again and test
    • *Open Screen #*: any Screen of `!Blocks-64.bin` as a 16x64 text page, saved back with line/character checks
    • *Open Block # (hex)*: any Block in a hex editor, for non-source ones

    **Install:** Extensions → *Install from VSIX…* (VS Code 1.75+). The SD tools also need `hdfmonkey` — see the guide.

    First release, born from my own workflow — rough edges expected. Feedback and bug reports very welcome here or on GitHub: https://github.com/mattsteeldue/vforth-next 🐉
