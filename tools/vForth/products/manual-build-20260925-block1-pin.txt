3. Par. 3.8 -- prose note after SEE NIP
-----------------------------------------

Error that predates this build: the definition following NIP is TUCK, not
SWAP, and $0305 is TUCK's CFA slot, not its NFA (the NFA is at $02FE).
Form chosen by the author (2026-09-26): keep $0305 and describe it.
>>>
The bytes that follow  - 05 03 E1 F1 - are the beginning of the
subsequent definition compiled in dictionary (TUCK in this case): 05 03
is TUCK's Mirror, i.e. the heap-pointer $0305 to its CFA. Try $0305 FAR
8 DUMP to inspect the HEAP: you'll see TUCK's xt $68E0 followed by
SWAP's NFA.
<<<

5. Glossary: BUFFER -- sentence to append
-----------------------------------------
>>>
The buffer holding BLOCK 1 is never reassigned: BLOCK 1 is the line
buffer used by INCLUDE, NEEDS and EVALUATE, and its content cannot be
re-read from disk.
<<<


6. Glossary: FLUSH -- sentence to append (optional)
---------------------------------------------------
>>>
Since BLOCK 1 is never reassigned, FLUSH does not write it back to disk
even if it was marked by UPDATE, and it can safely be used inside a file
being INCLUDEd. To rewrite BLOCK 1 on purpose use  1 BLOCK 1 0 R/W .
<<<


7. NEEDS/INCLUDE paragraph ("NEEDS exploits BLOCK number 1 ...") -- append
-------------------------------------------------------------------------
>>>
Since build 2026-09-25 the buffer holding BLOCK 1 is never recycled, so a
source file can read any number of other blocks while it is being
included without losing its own current line.
<<<
