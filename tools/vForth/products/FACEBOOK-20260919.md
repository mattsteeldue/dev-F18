vForth now has a home in Visual Studio Code! 🖥️➡️🐉

Together with the latest build (20260820) I am making available a small extension for VS Code that makes writing vForth source a lot more comfortable. It is a single file, vforth-0.1.0.vsix, in the tools/ folder of the repository, with a quick-start guide next to it.

What it does:

✅ Syntax colouring generated from the real core dictionary, telling core words, library words and your own definitions apart
✅ It warns you when you use a library word before the NEEDS that loads it, and tells you which NEEDS to add
✅ Hover over a word to see its HELP page, where it is defined and what loads it
✅ Go to definition, also on NEEDS and INCLUDE, and an outline of your file

And for those of us who test on CSpect:

✅ One command pushes the file you are editing straight into the SD card image, while CSpect is running. No REMOUNT, no closing the emulator: type NEEDS again and you are testing the new version
✅ Open any Screen of !Blocks-64.bin as a 16 x 64 text page, edit it, save it back with checks on line length and characters
✅ Open any Block in a hex editor, for the ones that are not source text: graphics, PERSISTENCE snapshots, the message table

Install: in VS Code, Extensions, "Install from VSIX...", pick the file. That is all. You need VS Code 1.75 or later; the SD tools also need hdfmonkey, explained in the guide.

It is a first release and it grew out of my own daily workflow, so it will have rough edges. I wrote it with the help of Claude Code, and it was tried on the whole vForth source tree, over 400 files, to keep false alarms low.

Try it, and if something breaks or something is missing, tell me: that is the best gift.
