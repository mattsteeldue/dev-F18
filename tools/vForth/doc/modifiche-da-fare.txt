[par. 3.20 -- Dictionary memory structure]
==============================================================

For example the two contiguous definitions SWAP and DUP appears in
memory as follow (as per build 2026-06-14, since it's perfectly possible
that a different build shows different addresses).

Heap memory:
NFA    0307      | 84 | 53 57 41 D0 |             | len |  'S' 'W' 'A' 'P' |
LFA    030C      | FE 02 |                    | 02FE |  heap-pointer to previous NFA definition
CFA    030E      | E9 68 |                    | 68E9 |  xt memory-address of this definition

Main memory:
Mirror 68E7      | 0E 03 |          | 030E | backward-heap-pointer to SWAP's CFA
 xt    68E9      | E1 | E3 | E5 | DD E9 |
                 | pop hl | ex (sp),hl | push hl | jp (ix) |

Heap memory:
NFA    0310      | 83 | 44 55 D0 |             | len |  'D' 'U' 'P' |
LFA    0314      | 07 03 |                    | 0307 |  heap-pointer to previous NFA definition SWAP
CFA    0316      | F0 68 |                    | 68F0 |  xt memory-address of this definition

Main memory:
Mirror 68EE      | 16 03 |          | 0316 | backward-heap-pointer to DUP's CFA
 xt    68F0      | E1 | E5 | E5 | DD E9 |
                 | pop hl | push hl | push hl | jp (ix) |

You can verify yourself all of that by typing some commands.

        SEE SWAP
        Nfa: E307 84
        Lfa: E30C 02FE TUCK
        Cfa: 68E9 E5E3
        68E9  E1 E3 E5 DD  E9 16 03 E1  ace]i  a
        68F1  E5 E5 DD E9  1E 03 F1 E1  ee]i  qa
        $E307 9 DUMP
        E307  84 53 57 41  D0 FE 02 E9   SWAP~ i
        E30F  68 83 44 55  D0 07 03 F0  h DUP  p
        $68E7 2 DUMP
        68E7  0E 03 E1 E3  E5 DD E9 16    ace]i

        SEE DUP
        Nfa: E310 83
        Lfa: E314 0307 SWAP
        Cfa: 68F0 E5E5
        68F0  E1 E5 E5 DD  E9 1E 03 F1  aee]i  q
        68F8  E1 E3 F5 E5  DD E9 27 03  acue]i'
        $E310 8 DUMP
        E310  83 44 55 D0  07 03 F0 68   DUP  ph
        $68EE 2 DUMP
        68EE  16 03 E1 E5  E5 DD E9 1E    aee]i
